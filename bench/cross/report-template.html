Jaunt、MoeJS、Jint 性能对比

同一批 JavaScript 脚本,三个引擎各自运行;测量日期 2026-11-06,Jaunt 与 Jint 在同一个 .NET 进程,MoeJS 是 Go 引擎,单独进程运行。

结论

  • Jaunt 与 MoeJS 综合接近,Jaunt 明显快于 Jint(约两倍)。Jaunt 和 MoeJS 的差距在一成到三成之间,随测试时机器负载浮动,不能当作精确值。
  • 按赢的测试数:…。差距集中在高级特性(JSON 往返、eval/new Function、Proxy、模板字符串、抛出错误),这些上 MoeJS 快几倍;其余类型两者互有胜负,Jaunt 在对象与类、字符串与正则、函数式、异步上略快。
  • 对 Jint,Jaunt 在绝大多数测试上更快;例外是 eval/new Function、JSON 往返、迭代器 helpers 等少数几项,Jint 反而更快。
  • MoeJS 目前不支持 Temporal、迭代器 helpers、Intl.Collator;Jaunt 和 Jint 都支持。

      测试方法与注意事项
      • 三个引擎运行同一批脚本,每个脚本定义 main() 并返回校验值,与 Node 的输出对照,保证结果正确。
      • 引擎依次运行,从不同时运行。「已预热」耗时是预热后多批计时的中位数;页面展示的是多轮里最好的一次,因为测试机器上可能同时有其他任务在占用 CPU;三个引擎是在同一时段测的。
      • 不同语言运行时(.NET 与 Go)的内存管理不同,绝对耗时不能完全等同,请主要看相对快慢。
      • 综合速度只统计三个引擎都支持的测试;MoeJS 不支持的三个测试不计入。
      • Jint 在两个测试(函数源码文本、日期格式)上的输出与 Node 不一致,耗时仍然显示。
      • 可复现:运行 bench/cross/run.sh,再用 bench/cross/make_report.py 生成本页。
